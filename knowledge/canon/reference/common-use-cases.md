# Common use cases

Source: clip 04 slide “Grok Bot: Common Use Cases” (~00:06:39–00:07:09). Week agenda also splits sessions as GTM / Engineering / Marketing / Admins (`x.ai/galaxy`).

## GTM

Example bots on slide: **Account Health**, **Sales Outbound**.

Pipeline built overnight, follow-ups drafted after every call, and a CRM that stays current. Outreach ships in your voice, ready for review.

## Engineering

Example bots: **Product Performance**, **Bug Reproduction**.

Bugs reproduced overnight, a repro pack dropped in the ticket, and hotspots that get pulled before standup. The writeup ships with screenshots, ready for review.

## Marketing

Example bots: **Talent Scout**, **Paid Media**.

Campaigns watched overnight, a budget drafted for the month, and creatives that get rotated when they go stale. Spend shifts sit in Slack, ready for review.

## Admins

Example bots: **Chief of Staff**, **Expense Manager**.

Calendars, travel, expenses, and inboxes handled end to end. The admin directs the work while Bots run the busywork.
