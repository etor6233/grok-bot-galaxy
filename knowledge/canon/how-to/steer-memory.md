# Steering and memory

Source: clips 07 and 09 Q&A.

- When a bot **refuses** or **asks questions**, treat that as a signal to **teach** or **steer**.
- Steering is stored in memory going forward. Example: never use first+last name, only first name.
- Memory lives in **S3 buckets**, long-lived and persistent, and **you can modify it**.
- You can tell a bot to forget / stop using something. Example: after deleting bots used in a demo, tell the Chief of Staff to stop delegating to those two.
- Nuance (clip 09, continues): a bot remembers what you told it; stopping delegation is an instruction on top of that memory — see clip 09 remainder in the timeline.
