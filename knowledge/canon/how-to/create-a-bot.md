# How to create a bot

Source: Amrita, Grok Bot 101, clip 05 ~00:00:39–00:01:43.

1. Open Grok Bot (chat list looks like iMessage).
2. Sidebar **+** → name the bot. Demo name: **Data Dan**.
3. The product infers purpose from the **name**. Example given: a bot named “workflow builder” already has an idea of the job.
4. Chips: “What do you mainly want me for?” — Data & analysis; Research & digests; Workflows & routines; Something else. You can ignore those and type or **voice** a first task in `Message [Bot]`.

First task in the demo: create a Google Form (two questions: cups of coffee per day; favorite SF coffee shops — Ritual, Fields, Sightglass, Blue Bottle). Voice mode was used to dictate that task.
