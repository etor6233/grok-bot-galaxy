## 00:05:05–00:06:55  [talking-head]
**Spoken:** Audience Q: "Because the Grok Bot can use computer use… will it eliminate or reduce the use of MCP-required websites? Where should the next move go — creating more MCPs for bots to use, or not creating any MCPs?" Amrita: "That's a really good question. And so I do think that going into the world going forward, a big part of how your work is going to get done is via computer use. Do I think that MCPs are going to go away? Absolutely not. I mean, the way I describe MCPs usually is like they're APIs for agents, right? And so a lot of times when I use an MCP, it's faster than a computer use. Like if I want to, for example, just immediately create a Google Doc, sometimes I'll opt to use the Google Doc MCP as opposed to computer use, because right now it's faster. But I don't know — I have a big feeling that computer use is going to get a lot faster, especially as the models get a lot better. So there could be a world where computer use becomes the main way of agents interacting with tools, than an MCP. I will say that for now, MCPs are probably a lot easier to monitor and to add guardrails to. Right now, in Cursor and SpaceX, you can whitelist and blacklist particular MCPs. So that's probably an advantage for MCPs for now, but I'm assuming that we'll start to see more guardrails being put for computer use in the future as well. It's a great question."
**On screen:** Talking-head; stream frame "Grok Bot Galaxy Day 2".
**Actions:** Amrita answers the MCP-vs-computer-use roadmap question.
**Facts:**
- Amrita's stance: computer use will be a very big part of how work gets done; MCPs won't go away ("APIs for agents")
- MCPs are currently faster for instant actions (example: Google Docs MCP beats computer use for creating a doc) and easier to monitor/guardrail (whitelist + blacklist in Cursor/SpaceX)
- Prediction: as models improve, computer use could become the main agent↔tool interface; more computer-use guardrails expected in the future
