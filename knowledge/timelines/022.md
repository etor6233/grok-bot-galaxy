## 00:06:20–00:10:00  [slide]
**Spoken:** Lingxi Li: "The next step comes, the automations, which is running on the Cursor cloud agents. That is a different era, because the agent could then be started based on some triggers — like you receive a Slack message… it can not only rely on you starting the agent: the agent can start on its own when you are not with your computer. The agent can also run 24/7, even when you are asleep. It can start based on the Slack messages it triggered. And another thing that it unlocks is it's no longer limited by how much your local computer can run. The whole idea of Cursor Cloud Agent is that it can run whatever is possible on your computer, on cloud. That means we can just give you 10 machines or even more to run things in parallel. Your agents will no longer fight for the same port… Everyone at [the] Cursor team has almost been 10x'd or even more. But we have also been thinking through what should be the next step. Agentic coding is already very good… What's more? What can make our lives easier? So the idea is we can possibly make Grok Bot — make some AI agent to help us write the prompt, to help us orchestrate. Because before that, I was able to manage 15 Cursor cloud agents, and it was already a lot. I have been context switching between different cloud agents, but I really wish there was another agent that can help me kick off the follow-up, help me queue the messages, help me nudge or interrupt the cloud agents when I think it shouldn't continue or it needs to be steered into a different direction."
